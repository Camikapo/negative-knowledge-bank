# Negative Knowledge Bank — фабрика гипотез из неудачных экспериментов

Прототип для хакатона (кейс «Фабрика гипотез», Норникель).

## Идея

Обычные базы знаний хранят **успешные** решения, а неудачные эксперименты
забываются — и для компании это огромная потеря. Мы строим **банк
негативного знания**, который на каждую неудачу фиксирует:

1. **что пробовали**
2. **почему не сработало**
3. **при каких условиях не сработало**
4. **что можно изменить, чтобы попробовать снова**

Когда исследователь ставит новую цель, система находит похожие прошлые
провалы и генерирует **проверяемые гипотезы, которые обходят причину
прошлого провала** — а не повторяют его.

Это отличает нас от «обычного» RAG: классический ассистент советует «попробуй
X», наш говорит «X уже пробовали при таких-то условиях и не вышло — измени вот
это».

## Как это работает (архитектура)

```
Цель исследователя
      │
      ▼
[Векторный поиск]  ──►  Банк неудачных экспериментов (JSON + embeddings)
      │                  (Yandex text-search-doc / text-search-query,
      │                   косинусная близость)
      ▼
Топ-N релевантных прошлых неудач
      │
      ▼
[Генерация гипотез]  (Yandex YandexGPT, JSON-вывод)
      │
      ▼
Гипотезы: формулировка · механизм · чем отличается от провала ·
          новизна · риски · ценность · план проверки
```

Работает через **Yandex AI Studio** по OpenAI-совместимому API.

## Установка

Нужен Python 3.10+, а также **API-ключ** и **Folder ID** из Yandex AI Studio.

```bash
pip install -r requirements.txt
```

Задайте учётные данные (нужны ОБА значения):

```bash
# Windows (PowerShell)
$env:YANDEX_API_KEY="ваш-api-ключ"
$env:YANDEX_FOLDER_ID="ваш-folder-id"

# Mac / Linux
export YANDEX_API_KEY=ваш-api-ключ
export YANDEX_FOLDER_ID=ваш-folder-id
```
## Запуск

### Вариант 1 — веб-интерфейс (демо)

```bash
streamlit run app.py
```

Откроется браузер. Введите цель, при желании ограничения, нажмите «Сгенерировать гипотезы».

### Вариант 2 — консоль

```bash
python run.py "повысить жаропрочность никелевого сплава на 15%"
```

С ограничениями: ""Стандартное литейное оборудование, без дорогих легирующих добавок

```bash
python run.py "снизить себестоимость шихты без потери прочности" --constraints "бюджет ограничен"
```

Результат печатается в консоль и сохраняется в `report.md`.

## Структура проекта

```
negative-knowledge-bank/
├── nkb_core.py                     # ядро: хранилище, поиск, генерация
├── run.py                          # консольный запуск
├── app.py                          # веб-интерфейс (Streamlit)
├── requirements.txt
├── README.md
└── data/
    └── failed_experiments.json     # банк неудачных экспериментов (демо-данные)
```

## Как пополнять банк

Добавьте запись в `data/failed_experiments.json`:

```json
{
  "id": "EXP-007",
  "title": "Короткое название",
  "tried": "что пробовали",
  "why_failed": "почему не сработало",
  "conditions": "при каких условиях (режимы, сырьё, оборудование)",
  "what_to_change": "что можно изменить",
  "domain": "металлургия",
  "source": "Отчёт №..."
}
```

Embedding для новой записи посчитается автоматически при загрузке.

## Технологии

- **Yandex AI Studio** — генерация (YandexGPT) и эмбеддинги
  (text-search-doc / text-search-query) через OpenAI-совместимый API.
- **Python** + библиотека `openai` (как клиент к Yandex-эндпоинту).
- **Streamlit** — веб-интерфейс.

Раздельные модели эмбеддингов для документов и запросов — рекомендованный
Яндексом способ, он повышает точность семантического поиска по сравнению с
единым эмбеддингом.
